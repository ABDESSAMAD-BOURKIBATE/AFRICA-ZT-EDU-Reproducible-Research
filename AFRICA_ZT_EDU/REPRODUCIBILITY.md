# Reproducibility Protocol

## 1. Scope

This artifact reproduces:

- the 30-seed synthetic policy experiment (3,000,000 requests by default);
- the differential-privacy utility experiment (50,000 synthetic cohort-count queries);
- the policy-registry staleness experiment (200,000 synthetic prohibited-transfer candidates);
- the 36-row analytical threat-control dataset and coverage figures;
- the single-host cryptographic/policy microbenchmark and its raw samples;
- every manuscript figure; and
- the 15-page IEEEtran PDF.

It does not reproduce a production deployment, a country-level legal conclusion, an institutional incident rate, or a compliance certification.

## 2. Requirements

- Python 3.10 or newer
- `cryptography==46.0.4`
- `numpy==2.3.5`
- `pandas==2.2.3`
- `matplotlib==3.10.8`
- A LaTeX distribution with `IEEEtran`, BibTeX, and the packages imported by `main.tex`

Install Python dependencies:

```bash
python3 -m pip install -r requirements.txt
```

## 3. Reproduce the policy simulation

From the project root:

```bash
python3 experiments/simulate_policy.py
```

Default parameters:

```text
requests per seed: 100,000
independent seeds: 30
first seed: 20260817
false-allow registry error: 0.25%
false-deny registry error: 0.10%
```

Outputs:

```text
data/seed_metrics.csv
data/results_summary.csv
data/dp_utility.csv
data/policy_staleness.csv
figures/false_permit_rate.pdf|png
figures/transfer_blocking.pdf|png
figures/data_minimization.pdf|png
figures/policy_latency.pdf|png
figures/dp_utility.pdf|png
figures/policy_staleness.pdf|png
```

The recorded policy outputs are deterministic for the supplied code, parameters, NumPy version, and seeds. A verification rerun reproduced the four generated CSV files byte-for-byte.

## 4. Reproduce the single-host benchmark

```bash
python3 scripts/benchmark.py --output-dir results
```

The benchmark measures:

- Ed25519 signing and verification of a 720-byte VC-like canonical JSON payload;
- AES-256-GCM encryption/decryption of 1, 10, and 100 KiB synthetic buffers;
- sequential first-match scans over 50 and 200 rules, with the matching permit rule placed last; and
- a composite authorization gate containing verification, 200-rule evaluation, 10 KiB encryption, and a hashed decision receipt.

Outputs:

```text
results/benchmark_raw.csv
results/benchmark_summary.csv
results/benchmark_environment.json
```

The recorded run contains 37,500 measured samples. The composite path contains 2,500 samples and records p50 = 0.120950 ms and p95 = 0.138447 ms on the supplied host. Benchmark values are expected to vary with CPU, OS, power mode, virtualization, process load, and library versions.

## 5. Regenerate contextual and architecture figures

After the simulation and benchmark:

```bash
python3 scripts/generate_figures.py
```

This command reads the contextual CSV files, the row-level threat-control scores, and the benchmark summary, then regenerates the analytical figures and calls the dedicated high-resolution architecture generator:

```text
figures/connectivity_context.pdf|png
figures/governance_context.pdf|png
figures/reference_architecture_v3.pdf|png
figures/threat_coverage.pdf|png
figures/benchmark_latency.pdf|png
```

Matplotlib is configured to embed TrueType outlines in PDF figures and avoid Type 3 figure fonts.

## 8. Provenance and validity boundaries

- Contextual indicators come from cited official sources and are stored with source notes.
- Request, cohort, institution, jurisdiction, and credential payload data are synthetic.
- The policy simulator's latency is generated by a declared model and is separate from the measured microbenchmark.
- The analytical comparator is deliberately specified in the paper; it is not a named product.
- Jurisdiction classes are abstract test profiles and must not be mapped to real countries without current legal and institutional review.
- The dated Malabo status values are a July 8, 2024 snapshot; they are not presented as a current 2026 ratification count.
